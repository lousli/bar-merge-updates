# Bar Merge 安卓测试版

此仓库只发布 APK 和版本信息，游戏源码保存在独立私有仓库。

[下载最新 APK](https://github.com/lousli/bar-merge-updates/releases/latest/download/BarMerge.apk)

## 手机安装与更新

- Android 8.0 及以上。第一次手动下载并安装 0.2.38 或更新版本。
- 保留原应用直接覆盖安装，不要先卸载。设置和已结算进度沿用，未结算的一晚需要重玩。
- 启动游戏会检查新版，也可在开场或设置中点击检查更新。
- 确认下载后，由安卓确认安装；首次可能需要允许「bar merge」安装应用。
- 更新需要网络；GitHub 不可达时无法更新，但仍可离线玩游戏。
- 这是测试版。手机安装授权、覆盖更新和不同机型的实际体验仍需验证。

[所有版本及更新说明](https://github.com/lousli/bar-merge-updates/releases)

每个版本提供 `BarMerge.apk`、`BarMerge.apk.sha256` 和 `update.json`。
